# FLE³

**Frame, Lead, Explain in 3 layers**

어려운 기술·업무 개념을 큰 그림과 적은 글로 설명하는 Codex 스킬입니다. 복잡한 설명은 기본적으로 브라우저에서 여는 단일 HTML 시각 자료를 만들고, 채팅에는 한 줄 요약과 파일 링크를 남깁니다.

## 무엇이 달라졌나요?

초기 FLE³는 채팅 답변과 작은 ASCII 그림에 머물렀습니다. 현재 버전은 다음 조건에서 HTML 시각 자료를 반드시 만듭니다.

- 설명할 대상에 여러 부분이나 단계가 있을 때
- 흐름, 구조, 비교, 원인과 결과를 보여줘야 할 때
- 사용자가 그림, 다이어그램, 시각적 설명, 위키형 설명을 요청할 때
- 설명이 한 문단을 넘어갈 때

아주 짧은 사실 질문이거나 사용자가 파일을 원하지 않을 때만 채팅 전용으로 답합니다.

## 결과물

HTML 페이지는 다음 구조를 가집니다.

1. 한 줄 답
2. 화면의 중심을 차지하는 큰 SVG 그림
3. 일상 비유 하나
4. 실제 원리 세 단계
5. 비유와 실제 원리의 차이
6. 다른 말로 한 줄 정리

[HTML 템플릿](assets/visual-lesson-template.html)은 반응형 레이아웃, 접근성 라벨, 모바일 대응을 포함합니다. 결과물은 외부 라이브러리 없이 브라우저에서 바로 열립니다.

디자인은 설명에 필요한 만큼만 사용합니다. 그라데이션, 유리 효과, 장식 원, 큰 그림자, 의미 없는 카드와 등장 애니메이션은 기본적으로 금지합니다. 요소를 지웠을 때 이해가 달라지지 않으면 그 요소를 삭제합니다.

## 리더 검수는 질문 크기에 맞춥니다

간단한 개념 설명은 필요, 확인된 사실, 잘못 믿기 쉬운 경계, 기억할 한 줄만 빠르게 확인합니다. 비교, 의사결정, 반박, 고위험 정보, 외부 공유물에는 [전체 익명 리더 검수](references/leader-lens.md)를 적용합니다.

- 요청한 수단보다 실제 필요를 먼저 찾습니다.
- 결론, 근거, 범위, 대안, 불확실성을 연결합니다.
- 사실, 추론, 가설, 미확인을 구분합니다.
- 숫자에는 산출 근거를, 가능 여부에는 비용 크기를 붙입니다.
- 항목 수나 규모가 커져 독자의 필요가 달라지면 설명 형태도 바꿉니다.
- 말로 약속하기보다 HTML, 렌더 화면, 계산, 테스트 같은 산출물을 확인합니다.
- 공격 시에는 누락 → 삭제 → 실제 독자 관점 순서로 검토합니다.
- 새 증거나 피드백이 오면 기존 결론을 방어하지 않고 다시 분류합니다.
- 최종본에는 결론, 필수 근거, 남은 불확실성, 다음 판단만 남깁니다.

이 분석은 결과물 뒤에서 조용히 수행됩니다. 간단한 질문에 전체 검수 문서를 매번 읽지 않지만, 쉬운 설명이라는 이유로 근거와 경계를 버리지도 않습니다.

## 속도 설계

일반적인 개념 설명은 빠른 경로를 사용합니다.

- 스킬을 한 번 읽고 설명 내용만 빠른 빌더에 넘깁니다.
- 빌더가 고정 템플릿 생성과 구조 검증을 한 번에 끝냅니다.
- 관련 없는 저장소 탐색, 참조 파일 전체 읽기, 브라우저 설치 여부 탐색을 하지 않습니다.
- 맞춤 레이아웃이나 외부 공유 수준의 결과물에서만 전체 참조와 데스크톱·모바일 렌더 검수를 엽니다.

## `eli5`와의 관계

현재 관찰된 `eli5` 플러그인과 FLE³는 이제 둘 다 HTML 시각 자료를 만들 수 있습니다. 따라서 “eli5는 그림, FLE³는 글”로 구분하면 안 됩니다.

| 항목 | 관찰된 `eli5` 플러그인 | FLE³ |
| --- | --- | --- |
| 기본 출력 | HTML 시각 아티팩트 | HTML 시각 레슨 + 짧은 채팅 링크 |
| 지시 구조 | 짧은 아티팩트 지시와 디자인·다이어그램 도구 | Frame → 전체 익명 리더 검수 → 3단 설명 → 시각 QA |
| 그림 | 큰 시각 자료 중심 | 큰 SVG/CSS 시각 자료 중심 |
| 추가 규칙 | 관찰된 짧은 본문에는 별도 정확성 규칙 없음 | 비유의 한계, 불확실성, 초보 설명 체크가 파일에 존재 |
| 설치 갱신 | 플러그인 캐시의 업데이트 흐름 | 설치한 Git 저장소를 직접 갱신 |

규칙의 존재는 확인된 사실이지만, FLE³가 더 정확하거나 더 이해하기 쉽다는 뜻은 아닙니다. 비교하려면 fresh context, 동일 입력, 순서 교차, 블라인드 채점, 실제 토큰·시간 측정이 필요합니다.

## 말투

FLE³는 사용자의 거친 자기표현을 감정 상담 요청으로 바꾸지 않습니다. 아주 낮은 난이도를 요청한 것으로 받아들이고 문장 자체를 쉽게 만듭니다.

- 반말 질문에는 차분하고 자연스러운 반말, 존댓말 질문에는 존댓말을 사용합니다.
- “괜찮아요” 같은 위로로 시작하지 않고 바로 핵심을 말합니다.
- 대부분의 문장은 12~15어절 안쪽으로 유지합니다.
- 한 문단에 낯선 기술 용어를 하나만 소개하고 바로 풀이합니다.
- 한 문장에 새 개념이 두 개 들어가면 나눕니다.
- 아기 말투, 억지 칭찬, 상담 말투, “쉽죠?”, 지능을 평가하는 표현을 사용하지 않습니다.
- 마지막은 이해도를 칭찬하지 않고 “한 줄만 기억하면 돼: …”처럼 내용으로 정리합니다.
- 이해가 안 되면 같은 문장을 반복하지 않고 그림과 비유를 바꿉니다.

리더 검토 기준은 완전히 일반화되어 있으며 특정 인물, 고유 말투, 사내 조직, 실제 내부 사건을 식별할 수 있는 정보를 포함하지 않습니다.

## 설치

업데이트 상태를 확인할 수 있도록 파일 복사보다 Git clone을 권장합니다.

```bash
git clone https://github.com/skyepodium/fle3.git ~/.codex/skills/fle3
```

호출 예시:

```text
$fle3 API가 무엇인지 그림으로 쉽게 설명해줘.
```

기본 결과물은 `artifacts/fle3/<topic>.html`에 생성됩니다.

## 업데이트

FLE³는 자동 업데이트되지 않습니다.

```bash
git -C ~/.codex/skills/fle3 pull --ff-only
```

단순 복사로 설치했다면 현재 버전을 자동으로 확인할 수 없습니다. 최신 저장소를 다시 받아 교체해야 합니다.
